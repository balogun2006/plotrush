# PlotRush design brief

## Visual direction

Premium, approachable social mystery entertainment. Midnight purple `#211B35`, lime actions `#D9F36A`, warm ivory surfaces and restrained coral accents. Rounded cards, clear sans-serif typography, readable text and cinematic fictional Nigerian story settings. No graphic violence in starter cases. Keep controls high-contrast, keyboard accessible and touch targets at least44px.

## Original six-screen flow

1. Discover a case: strong cover art, premise, duration, player count and free trial action.
2. Unlock: clear case/mode/price, one host pays and friends join free.
3. Invite: room code, share link, joined/ready avatars and start action.
4. Investigate: private evidence, notes, sharing and group board.
5. Accuse: suspect and reason choices, hidden votes until reveal.
6. Reveal: evidence-backed explanation, spoiler-free sharing and another case.

## Additional required screens

Home has separate free solo and group choices. Add illustrated theme cards, theme landing pages, mobile filter sheet, desktop filters, case metadata badges, optional interests onboarding, editable interests and For you/Featured recommendation rails. Solo must feel complete without friends. Active paid games are ad-free; free ad placements are clearly labelled and separate from clue content.

The detailed interaction/content/accessibility specifications are in [chapter01](implementation/01_PRODUCT_AND_DELIVERY_PLAN.md) and [chapter07](implementation/07_THEMES_DISCOVERY_AND_RECOMMENDATIONS.md). No image file is required to understand the implementation contract; create production UI components rather than using screenshots as the interface.
