# PlotRush roadmap

The detailed source of truth is [the31-task backlog](docs/implementation/06_AGENT_BACKLOG_AND_ACCEPTANCE.md). This roadmap groups work into deployable milestones; nothing below is implemented yet.

| Milestone | Work | Exit condition |
|---|---|---|
| Foundation | MN-001–004,025; scaffold, design system, Auth/RLS, content/taxonomy importer | Secure database-backed app and validated draft import |
| Solo and discovery | MN-005–006,026–028; daily play, evidence, result, filters and interests | Anonymous solo completion plus correct personalised/editorial discovery |
| Group gameplay | MN-007–010; lobby, private evidence, reconnect, votes/reveal | Independent browser contexts complete the same case correctly |
| Commerce and editorial | MN-011–014,029; verified purchases/refunds and content administration | Sandbox money edge cases and approved version workflow pass |
| Direct advertising | MN-015–017,030; campaigns, review/payment, caps/reporting | Honest measured delivery on eligible free placements |
| Google readiness | MN-018–019; consent, approved adapter and optional rewarded hints | No-fill/decline functional; live enablement only after actual approval |
| Verification and staging | MN-020–022,031; analytics, security/accessibility/load/restore | Evidence against launch gates; real staging environment |
| Content and beta | MN-023–024; supply, provider activation and launch | Reviewed inventory, support/monitoring, deployment manifest |

Private alpha may run with fewer cases and live monetisation disabled. A broad daily/theme-led launch needs the content thresholds in chapters01/07. App-store apps, subscriptions, asynchronous multiplayer and self-service advertisers remain later validation-driven work.
